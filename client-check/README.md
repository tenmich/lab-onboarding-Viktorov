`pc_info.bat` запускается двойным щелчком. Он собирает сведения о компьютере, сверяет список установленных программ с эталонными списками и пишет рекомендации. Всё выводится в окно и одновременно сохраняется в `pc_report.txt` рядом со скриптом.

## Что изменилось по сравнению с частью 1

| Было (часть 1) | Стало (часть 2) |
|---|---|
| Каждая строка выводилась дважды: `echo` на экран и `echo >> файл` | Подпрограмма `:log "текст"`: выводит строку на экран и дописывает её в отчёт. Пустая строка через `echo(`, текст через отложенное расширение `!MSG!`, поэтому символы `( ) < > & \|` в названиях программ не ломают команду |
| Переменные не очищались, пустой результат не проверялся | Подпрограмма `:psget` очищает переменную перед запросом. После запроса проверяется `if not defined`, и в отчёт пишется «данные получить не удалось». Скрипт при этом продолжает работу |
| Память и диск в целых ГБ через `set /a` | Деление больших чисел выполняет PowerShell (`Get-CimInstance`), результат с одним знаком после запятой. `wmic` в Windows 11 25H2 отсутствует |
| Список программ выводился потоком | Список сохраняется во временный файл, повторы убираются (`sort /unique`). Опрашиваются три ветки: `Uninstall`, `WOW6432Node\Uninstall`, `HKCU\...\Uninstall`. Антивирус берётся из `root/SecurityCenter2`, потому что Defender не записан в `Uninstall` |
| — | Раздел «Проверка базового ПО» (5 категорий) |
| — | Раздел «ПО, не относящееся к офисным задачам» (4 группы) |
| — | Временная метка, сообщения о ходе работы, итог (сколько категорий проверено и сколько рекомендаций выдано, полный путь к отчёту). Временные файлы удаляются |

## Базовый набор офисного ПО и почему он такой

| Категория | Признаки (поиск без учёта регистра) | Почему нужна |
|---|---|---|
| Офисный пакет | Microsoft Office, Microsoft 365, LibreOffice, OpenOffice, OnlyOffice, МойОфис, MyOffice, WPS Office, Р7-Офис | Основная офисная работа с .docx/.xlsx/.pptx. Учтены отечественные пакеты (импортозамещение) |
| Браузер | Google Chrome, Mozilla Firefox, Yandex/Яндекс, Opera, Vivaldi, Chromium | Работа с веб-сервисами и порталами. Edge отмечается отдельно как компонент Windows, а не как результат настройки |
| Чтение PDF | Acrobat, Foxit, SumatraPDF, PDF-XChange, Okular | Договоры, счета, сканы, печатные формы |
| Архиватор | 7-Zip, WinRAR, WinZip, PeaZip, Bandizip | Вложения в почте (zip/rar/7z) |
| Антивирус | Windows/Microsoft Defender, Kaspersky, ESET, Dr.Web, Avast, Bitdefender | Минимальное требование информационной безопасности |

## Признаки ПО, не относящегося к офисным задачам

1. Игровое ПО: Steam, Epic Games, GOG Galaxy, Origin, EA app, Ubisoft Connect, Battle.net, Riot, game, gaming.
2. Торрент-клиенты: torrent, uTorrent, BitTorrent, qBittorrent, Vuze. Это самая важная группа: нагрузка на сеть и риск нежелательного ПО.
3. Мессенджеры: Discord, Telegram, WhatsApp, Viber, Skype. Формулировка проверочная, а не запрещающая: в части организаций это рабочий инструмент.
4. Развлечения и оформление: Wallpaper Engine, OBS Studio, Soundpad, AIMP, Winamp, KMPlayer, PotPlayer, iTunes, Spotify.

Вывод скрипта — **рекомендация к проверке, а не указание к удалению**. Решение принимает администратор.

## Как проверялась логика (шаг 8)

В скрипт добавлен тестовый режим. Если рядом с `pc_info.bat` лежит `test_apps.txt`, его строки добавляются в список программ. Строки из `test_exclude.txt` из списка убираются. Без этих файлов скрипт работает в обычном режиме.

1. **Ветка «излишнее ПО».** На моём компьютере нет игр и торрентов, поэтому в `test_apps.txt` были записаны строки `Steam (TEST)`, `qBittorrent 5.0 (TEST)`, `Discord (TEST)`. Результат прогона:
   ```
   1. Игровое ПО и игровые платформы
       - Steam (TEST)
   2. Торрент-клиенты и файлообмен
       - qBittorrent 5.0 (TEST)
   3. Мессенджеры для личного общения
       - Discord (TEST)
   ```
2. **Ветка «недостающее ПО».** В `test_exclude.txt` было записано `WinRAR`, то есть единственный архиватор на машине временно исключён из поиска. Результат:
   ```
   [!]  Архиватор: Не обнаружен архиватор. Для работы с вложениями в почте (zip, rar, 7z) рекомендуется установить 7-Zip или WinRAR.
   ```
   В этом прогоне «Выдано рекомендаций» выросло с 5 до 8.
3. После проверки тестовые файлы удалены. `pc_report.txt` и `screenshot_audit.png` получены обычным прогоном без тестовых данных.

## Ограничения решения

- Поиск идёт по подстроке, поэтому возможны ложные срабатывания (например, слово `Game` в названии системного компонента) и пропуски, если программа названа иначе, чем в списке признаков.
- Видны только программы, записанные в разделах `Uninstall` реестра. Портативные программы и приложения Microsoft Store (UWP) не учитываются.
- Для кириллических признаков `findstr` сравнивает с учётом регистра (без учёта регистра работает только для латиницы).
- Скрипт не знает, когда программа запускалась в последний раз: это намеренно (см. задание), сверка идёт только с эталонным списком.
- Нужен PowerShell (есть в любой Windows 10/11). `wmic` не используется, потому что в новых сборках Windows 11 его нет.
